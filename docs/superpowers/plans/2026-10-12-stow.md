# Stow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Stow, a personal macOS 27 menu bar utility that hides chosen apps' menu bar icons behind one toggle, using macOS's private exam-mode allow-list.

**Architecture:**
- A Swift package with three targets:
  - `ExamModeBridge`: about 60 lines of Objective-C that load `MenuBarClientCore` when the app runs.
  - `StowKit`: all logic and UI, unit-tested against fakes.
  - `Stow`: a tiny executable entry point.
- `HideController` is a callback-driven state machine: Shown / Hidden / Unavailable. It builds the allow-list and talks to a `MenuBarRestriction` protocol, live or fake.
- AppKit owns the menu bar item. SwiftUI renders the System Settings–style window.
- `scripts/install.sh` builds the app, signs it with the local Apple Development identity, installs it to `/Applications` and relaunches it.

**Tech Stack:** Swift 6.4 (Swift 6 language mode, strict concurrency), Xcode 27 toolchain, SwiftPM, AppKit, SwiftUI + Observation, Carbon hot keys, ApplicationServices (Accessibility), ServiceManagement, Swift Testing. No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-12-stow-design.md`, with the background in `docs/macos-27-menu-bar-findings.md`. Read both before starting.

## Global Constraints

- **macOS 27 only.** `LSMinimumSystemVersion` 27.0; package platform `.macOS("27.0")`.
- **The only permission is Accessibility** (for the app list). Stow must never request or need Screen Recording or Input Monitoring.
- **It runs from `/Applications/Stow.app`, unsandboxed.** Exam mode only recognizes the installed copy.
- **It's signed with the local Apple Development identity**, auto-detected from the keychain. Never ad-hoc.
- **It fails safe:** no error path may leave icons hidden.
- **No third-party packages.**
- **Bundle ID `studio.longbrook.stow`**, display name `Stow`.
- **Swift 6 language mode with strict concurrency.** All UI and state types are `@MainActor`.
- **UI copy:** strings are exactly as written in this plan (from spec §5). No emoji anywhere: UI, code, comments, docs. The ⌃⌥⇧⌘ key symbols are fine.
- **Imports in tests:** test files that touch AppKit or SwiftUI types must `import AppKit` / `import SwiftUI` themselves. `@testable import StowKit` doesn't re-export them.
- **Git:**
  - stage explicit paths (never `git add -A` or `git add .`), and run `git status` before each commit;
  - commit and push are separate steps, and this plan never pushes;
  - every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Working directory for every command:** `~/Sites/stow`.

## Review Focus

These failure modes are implied by the spec but easy to miss. Each one has a pinning test in the task named.

1. **Double-clicking the drawer while a hide is still being applied** should end Shown with no assertion left alive. (Task 5, `doubleToggleWhileActivatingEndsShownWithNoAssertion`)
2. **A burst of app launches while hidden** (about 10 apps at login) should cause one allow-list refresh, not ten. (Task 6, `launchBurstRefreshesOnce`)
3. **Quitting while a hide is mid-flight** should leave no assertion behind once the late activation completes. (Task 5, `quitWhileActivatingLeavesNoAssertion`; SIGTERM path in Task 14)
4. **Damaged or hand-edited preferences** (wrong types, a 7-second delay, a ⇧-only shortcut) should give sane defaults or the nearest valid value, and never crash. (Task 3, `corruptedValuesFallBack` and `delaysClampToNearest`)
5. **A hidden app that has since been uninstalled, or is running but invisible because Stow hid it,** should still be listed: by bundle ID if it has no name, and not marked "Not running" if it is running. (Task 11, `hiddenUninstalledAppStillListed` and `hiddenRunningAppNotMarkedNotRunning`)

`Sources/ExamModeBridge/ExamModeBridge.m`:

```objc
// Loads macOS 27's private MenuBarClientCore at run time and drives its exam-mode
// (assessment) allow-list. Nothing links the framework at build time: if a macOS
// update removes or renames it, Stow reports "unavailable" instead of failing to
// launch. API usage learned from dwarvesf/hidden (MIT); this is a fresh
// implementation. Background: docs/macos-27-menu-bar-findings.md.
#import "ExamModeBridge.h"
#import <dlfcn.h>

// Shapes of the private classes, declared so ARC applies normal init and ownership rules.
@protocol SXAssessmentConfiguration <NSObject>
- (instancetype)initWithAllowedSystemItems:(NSArray<NSNumber *> *)systemItems
                  allowedBundleIdentifiers:(NSArray<NSString *> *)bundleIdentifiers;
@end

@protocol SXAssessmentAssertion <NSObject>
- (void)activateWithConfiguration:(id)configuration
                completionHandler:(void (^)(NSError * _Nullable error))completion;
- (void)invalidate;
@end

static NSString *const SXFrameworkPath = @"/System/Library/PrivateFrameworks/MenuBarClientCore.framework/MenuBarClientCore";
static NSString *const SXConfigurationClassName = @"MBAssessmentModeConfiguration";
static NSString *const SXAssertionClassName = @"MBAssessmentModeAssertion";
static NSString *const SXErrorDomain = @"studio.longbrook.stow.ExamMode";

static NSError *SXError(NSString *reason) {
    return [NSError errorWithDomain:SXErrorDomain code:1 userInfo:@{NSLocalizedDescriptionKey: reason}];
}

BOOL SXExamModeIsAvailable(void) {
    if (dlopen(SXFrameworkPath.fileSystemRepresentation, RTLD_NOW | RTLD_LOCAL) == NULL) {
        return NO;
    }
    Class configuration = NSClassFromString(SXConfigurationClassName);
    Class assertion = NSClassFromString(SXAssertionClassName);
    return configuration != Nil && assertion != Nil
        && [configuration instancesRespondToSelector:@selector(initWithAllowedSystemItems:allowedBundleIdentifiers:)]
        && [assertion instancesRespondToSelector:@selector(activateWithConfiguration:completionHandler:)]
        && [assertion instancesRespondToSelector:@selector(invalidate)];
}

void SXExamModeActivate(NSArray<NSNumber *> *systemItems,
                        NSArray<NSString *> *bundleIDs,
                        void (^completion)(id _Nullable assertion, NSError * _Nullable error)) {
    void (^finish)(id, NSError *) = ^(id assertion, NSError *error) {
        dispatch_async(dispatch_get_main_queue(), ^{ completion(assertion, error); });
    };
    if (!SXExamModeIsAvailable()) {
        finish(nil, SXError(@"Hiding isn't available on this version of macOS."));
        return;
    }
    @try {
        // Both lists must be NSArrays: the framework indexes into them (an NSSet raises -objectAtIndex:).
        id<SXAssessmentConfiguration> configuration =
            [(id<SXAssessmentConfiguration>)[NSClassFromString(SXConfigurationClassName) alloc]
                initWithAllowedSystemItems:[systemItems copy]
                  allowedBundleIdentifiers:[bundleIDs copy]];
        id<SXAssessmentAssertion> assertion = [[NSClassFromString(SXAssertionClassName) alloc] init];
        if (configuration == nil || assertion == nil) {
            finish(nil, SXError(@"Couldn't create the exam-mode configuration."));
            return;
        }
        [assertion activateWithConfiguration:configuration completionHandler:^(NSError *error) {
            finish(error == nil ? assertion : nil, error);
        }];
    } @catch (NSException *exception) {
        finish(nil, SXError([NSString stringWithFormat:@"%@: %@", exception.name, exception.reason]));
    }
}

void SXExamModeInvalidate(id assertion) {
    @try {
        if ([assertion respondsToSelector:@selector(invalidate)]) {
            [(id<SXAssessmentAssertion>)assertion invalidate];
        }
    } @catch (NSException *exception) {
        NSLog(@"Stow: invalidate raised %@: %@", exception.name, exception.reason);
    }
}
```

```swift
import AppKit
import Carbon.HIToolbox

/// A global keyboard shortcut in Carbon terms (what RegisterEventHotKey takes).
public struct Shortcut: Equatable, Sendable {
    /// Carbon virtual key code (kVK_*).
    public var keyCode: UInt32
    /// Carbon modifier mask: cmdKey 256, shiftKey 512, optionKey 2048, controlKey 4096.
    public var modifiers: UInt32

    public init(keyCode: UInt32, modifiers: UInt32) {
        self.keyCode = keyCode
        self.modifiers = modifiers
    }

    /// ⌃⌥H.
    public static let defaultShortcut = Shortcut(keyCode: UInt32(kVK_ANSI_H), modifiers: UInt32(controlKey | optionKey))

    /// A usable global shortcut needs at least one of ⌃ ⌥ ⌘. Shift alone is not enough.
    public var isValid: Bool {
        modifiers & UInt32(controlKey | optionKey | cmdKey) != 0
    }

    /// Builds a shortcut from a key event. Returns nil when no ⌃ ⌥ ⌘ is held.
    public static func from(keyCode: UInt16, flags: NSEvent.ModifierFlags) -> Shortcut? {
        var mask: UInt32 = 0
        if flags.contains(.control) { mask |= UInt32(controlKey) }
        if flags.contains(.option) { mask |= UInt32(optionKey) }
        if flags.contains(.shift) { mask |= UInt32(shiftKey) }
        if flags.contains(.command) { mask |= UInt32(cmdKey) }
        let shortcut = Shortcut(keyCode: UInt32(keyCode), modifiers: mask)
        return shortcut.isValid ? shortcut : nil
    }

    /// For example "⌃⌥H". `translate` maps a key code to its character on the current
    /// keyboard layout; when it returns nil the US (ANSI) name is used.
    @MainActor
    public func displayString(translate: @MainActor (UInt32) -> String? = KeyNames.layoutCharacter) -> String {
        var text = ""
        if modifiers & UInt32(controlKey) != 0 { text += "⌃" }
        if modifiers & UInt32(optionKey) != 0 { text += "⌥" }
        if modifiers & UInt32(shiftKey) != 0 { text += "⇧" }
        if modifiers & UInt32(cmdKey) != 0 { text += "⌘" }
        return text + KeyNames.name(for: keyCode, translate: translate)
    }
}

        guard let source = TISCopyCurrentKeyboardLayoutInputSource()?.takeRetainedValue(),
              // The kTISPropertyUnicodeKeyLayoutData global isn't concurrency-safe in Swift 6; use its value.
              let raw = TISGetInputSourceProperty(source, "TISPropertyUnicodeKeyLayoutData" as CFString)
        else { return nil }
        let data = Unmanaged<CFData>.fromOpaque(raw).takeUnretainedValue() as Data
        var deadKeys: UInt32 = 0
        var characters = [UniChar](repeating: 0, count: 4)
        var length = 0
        let status = data.withUnsafeBytes { buffer -> OSStatus in

        return text.isEmpty ? nil : text.uppercased()
```

```swift
import Foundation

/// How long icons stay visible after you reveal them.
public enum RehideDelay: Int, CaseIterable, Sendable, Identifiable {
    case never = 0
    case fiveSeconds = 5
    case tenSeconds = 10
    case thirtySeconds = 30
    case oneMinute = 60

    public var id: Int { rawValue }

    /// nil means never re-hide.
    public var seconds: TimeInterval? { self == .never ? nil : TimeInterval(rawValue) }

    public var title: String {
        switch self {
        case .never: "Never"
        case .fiveSeconds: "5 seconds"
        case .tenSeconds: "10 seconds"
        case .thirtySeconds: "30 seconds"
        case .oneMinute: "1 minute"
        }
    }

    /// The allowed value closest to `seconds`. Zero or less means Never; ties go to the shorter delay.
    public static func nearest(to seconds: Int) -> RehideDelay {
        guard seconds > 0 else { return .never }
        let timed = allCases.filter { $0 != .never }
        return timed.min { a, b in
            let da = abs(a.rawValue - seconds), db = abs(b.rawValue - seconds)
            return da != db ? da < db : a.rawValue < b.rawValue
        }!
    }
}

/// Stow's saved settings. The login-item state is deliberately not stored here:
/// it's read live from SMAppService so there's one source of truth (spec 6.3).
@MainActor
public final class Preferences {
    enum Key {
        static let hiddenBundleIDs = "hiddenBundleIDs"
        static let rehideDelaySeconds = "rehideDelaySeconds"
        static let shortcutKeyCode = "shortcutKeyCode"
        static let shortcutModifiers = "shortcutModifiers"
        static let hasCompletedFirstRun = "hasCompletedFirstRun"
    }

    private let defaults: UserDefaults

    public init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
    }

    /// Apps to hide, by bundle ID. Always sorted, unique, without empty strings.
    public var hiddenBundleIDs: [String] {
        get {
            let raw = defaults.array(forKey: Key.hiddenBundleIDs) ?? []
            return Self.normalized(raw.compactMap { $0 as? String })
        }
        set { defaults.set(Self.normalized(newValue), forKey: Key.hiddenBundleIDs) }
    }

    public func isHidden(_ bundleID: String) -> Bool {
        hiddenBundleIDs.contains(bundleID)
    }

    public func setHidden(_ bundleID: String, _ hidden: Bool) {
        var ids = Set(hiddenBundleIDs)
        if hidden { ids.insert(bundleID) } else { ids.remove(bundleID) }
        hiddenBundleIDs = Array(ids)
    }

    public var rehideDelay: RehideDelay {
        get {
            guard let value = defaults.object(forKey: Key.rehideDelaySeconds) as? Int else { return .tenSeconds }
            return RehideDelay(rawValue: value) ?? .nearest(to: value)
        }
        set { defaults.set(newValue.rawValue, forKey: Key.rehideDelaySeconds) }
    }

    /// nil means the user cleared the shortcut. Missing or unusable stored values give ⌃⌥H.
    public var shortcut: Shortcut? {
        get {
            guard let code = defaults.object(forKey: Key.shortcutKeyCode) as? Int else { return .defaultShortcut }
            if code == -1 { return nil }
            guard (0...0xFFFF).contains(code),
                  let modifiers = defaults.object(forKey: Key.shortcutModifiers) as? Int, modifiers >= 0
            else { return .defaultShortcut }
            let shortcut = Shortcut(keyCode: UInt32(code), modifiers: UInt32(modifiers))
            return shortcut.isValid ? shortcut : .defaultShortcut
        }
        set {
            if let shortcut = newValue {
                defaults.set(Int(shortcut.keyCode), forKey: Key.shortcutKeyCode)
                defaults.set(Int(shortcut.modifiers), forKey: Key.shortcutModifiers)
            } else {
                defaults.set(-1, forKey: Key.shortcutKeyCode)
                defaults.removeObject(forKey: Key.shortcutModifiers)
            }
        }
    }

    public var hasCompletedFirstRun: Bool {
        get { defaults.bool(forKey: Key.hasCompletedFirstRun) }
        set { defaults.set(newValue, forKey: Key.hasCompletedFirstRun) }
    }

    private static func normalized(_ ids: [String]) -> [String] {
        Array(Set(ids.filter { !$0.isEmpty })).sorted()
    }
}
```

```swift
import AppKit

/// Exam mode is an allow-list: anything not listed disappears from the menu bar,
/// including Stow's own icon, so Stow always lists itself (spec 4.2).
public enum AllowList {
    /// macOS's own menu bar items to keep: clock, Wi-Fi, Control Center and so on.
    /// Same range upstream Hidden Bar uses.
    public static let systemItems: [Int] = Array(0..<64)

    public static func compute(running: [String], hidden: [String], own: String) -> [String] {
        let hiddenSet = Set(hidden).subtracting([own])
        var allowed = Set(running.filter { !$0.isEmpty })
        allowed.insert(own)
        return allowed.subtracting(hiddenSet).sorted()
    }
}

public enum RunningApps {
    /// Bundle IDs of running apps that can own menu bar icons (regular and accessory apps).
    @MainActor
    public static func bundleIDs(in workspace: NSWorkspace = .shared) -> [String] {
        workspace.runningApplications
            .filter { $0.activationPolicy == .regular || $0.activationPolicy == .accessory }
            .compactMap(\.bundleIdentifier)
    }
}

/// Exam mode only recognizes the copy LaunchServices knows as Stow. Any other copy
/// would hide its own icon, so Stow refuses to hide from anywhere else (spec 4.6).
public enum InstallLocation {
    public static let expectedPath = "/Applications/Stow.app"

    public static func isExpected(_ bundleURL: URL) -> Bool {
        bundleURL.standardizedFileURL.resolvingSymlinksInPath().path == expectedPath
    }
}
```

```swift
import Foundation
@testable import StowKit

struct FakeRefusal: LocalizedError {
    var errorDescription: String? { "refused" }
}

/// Records every activate and invalidate, in order. Completes immediately unless
/// `holdCompletions` is set; held completions run when the test calls `releasePending()`.
@MainActor final class FakeRestriction: MenuBarRestriction {
    enum Event: Equatable {
        case activate([String])
        case invalidate(Int)
    }

    @MainActor final class Token: RestrictionToken {
        let id: Int
        private weak var owner: FakeRestriction?
        private(set) var isInvalidated = false

        init(id: Int, owner: FakeRestriction) {
            self.id = id
            self.owner = owner
        }

        func invalidate() {
            guard !isInvalidated else { return }
            isInvalidated = true
            owner?.events.append(.invalidate(id))
        }
    }

    var isAvailable = true
    var refuse = false
    var holdCompletions = false
    var events: [Event] = []
    private(set) var lastSystemItems: [Int] = []
    private var pending: [(refused: Bool, completion: @MainActor (Result<any RestrictionToken, any Error>) -> Void)] = []
    private var tokens: [Token] = []
    private var nextID = 1

    var liveTokens: [Token] { tokens.filter { !$0.isInvalidated } }
    var activations: [[String]] { events.compactMap { if case .activate(let ids) = $0 { ids } else { nil } } }

    func activate(allowing bundleIDs: [String], systemItems: [Int],
                  completion: @escaping @MainActor (Result<any RestrictionToken, any Error>) -> Void) {
        events.append(.activate(bundleIDs))
        lastSystemItems = systemItems
        if holdCompletions {
            pending.append((refused: refuse, completion: completion))
        } else {
            complete(completion, refused: refuse)
        }
    }

    func releasePending() {
        let waiting = pending
        pending.removeAll()
        for entry in waiting { complete(entry.completion, refused: entry.refused) }
    }

    private func complete(_ completion: @MainActor (Result<any RestrictionToken, any Error>) -> Void, refused: Bool) {
        if refused {
            completion(.failure(FakeRefusal()))
            return
        }
        let token = Token(id: nextID, owner: self)
        nextID += 1
        tokens.append(token)
        completion(.success(token))
    }
}
```

```swift
import Foundation
@testable import StowKit

/// A scheduler whose clock only moves when a test calls `advance(by:)`.
@MainActor final class ManualScheduler: Scheduling {
    @MainActor final class Entry: ScheduledTask {
        let fireAt: TimeInterval
        let action: @MainActor () -> Void
        var isCancelled = false

        init(fireAt: TimeInterval, action: @escaping @MainActor () -> Void) {
            self.fireAt = fireAt
            self.action = action
        }

        func cancel() { isCancelled = true }
    }

    private(set) var now: TimeInterval = 0
    private var entries: [Entry] = []

    var pendingCount: Int { entries.filter { !$0.isCancelled }.count }

    func schedule(after seconds: TimeInterval, _ action: @escaping @MainActor () -> Void) -> any ScheduledTask {
        let entry = Entry(fireAt: now + seconds, action: action)
        entries.append(entry)
        return entry
    }

    /// Moves the clock forward, firing due work in time order. Work may schedule more work.
    func advance(by seconds: TimeInterval) {
        let target = now + seconds
        while let next = entries.filter({ !$0.isCancelled && $0.fireAt <= target + 1e-9 })
            .min(by: { $0.fireAt < $1.fireAt }) {
            now = next.fireAt
            next.isCancelled = true
            next.action()
        }
        now = target
    }
}
```

```swift
/// A cancellable piece of scheduled work.
@MainActor public protocol ScheduledTask {
    func cancel()
}

/// Runs work later on the main actor. Injected so tests control time.
@MainActor public protocol Scheduling {
    func schedule(after seconds: TimeInterval, _ action: @escaping @MainActor () -> Void) -> any ScheduledTask
}

/// The real scheduler: a sleeping task on the main actor.
@MainActor public final class TaskScheduler: Scheduling {
    public init() {}

    public func schedule(after seconds: TimeInterval, _ action: @escaping @MainActor () -> Void) -> any ScheduledTask {
        let task = Task { @MainActor in
            try? await Task.sleep(for: .seconds(seconds))
            if !Task.isCancelled { action() }
        }
        return TaskHandle(task: task)
    }
}

@MainActor private struct TaskHandle: ScheduledTask {
    let task: Task<Void, Never>
    func cancel() { task.cancel() }
```

```swift
import Foundation

/// Why Stow can't hide right now. Stow behaves as Shown meanwhile (spec 4.1, 4.6).
public enum UnavailableReason: Equatable, Sendable {
    case notInApplications
    case frameworkMissing
    case activationFailed(String)
}

public enum HideState: Equatable, Sendable {
    case shown
    case hidden(count: Int)
    case unavailable(UnavailableReason)
}

/// The Hidden / Shown / Unavailable state machine (spec 4).
///
/// Callback-driven on purpose. Every request bumps `generation`, and a completion
/// from an older generation is invalidated on arrival. That makes double clicks and
/// quitting mid-activation safe: a late assertion can never stick.
@MainActor
public final class HideController {
    public private(set) var state: HideState = .shown {
        didSet { if state != oldValue { onStateChange?(state) } }
    }

    /// Called on every state change. The menu bar icon listens to this.
    public var onStateChange: ((HideState) -> Void)?

    private let restriction: any MenuBarRestriction
    private let preferences: Preferences
    private let scheduler: any Scheduling
    private let runningBundleIDs: @MainActor () -> [String]
    private let isInstalledCorrectly: @MainActor () -> Bool
    private let isBusy: @MainActor () -> Bool
    private let ownBundleID: String

    private var token: (any RestrictionToken)?
    private var wantsHidden = false
    private var generation = 0

    public init(restriction: any MenuBarRestriction,
                preferences: Preferences,
                scheduler: any Scheduling,
                runningBundleIDs: @escaping @MainActor () -> [String],
                isInstalledCorrectly: @escaping @MainActor () -> Bool,
                isBusy: @escaping @MainActor () -> Bool,
                ownBundleID: String) {
        self.restriction = restriction
        self.preferences = preferences
        self.scheduler = scheduler
        self.runningBundleIDs = runningBundleIDs
        self.isInstalledCorrectly = isInstalledCorrectly
        self.isBusy = isBusy
        self.ownBundleID = ownBundleID
    }

    /// Launch, including at login: hide right away if there's anything to hide.
    public func start() {
        if preferences.hiddenBundleIDs.isEmpty {
            state = .shown
        } else {
            hide()
        }
    }

    /// Click, shortcut or menu item. Goes by the intended state, so a second click
    /// while a hide is still being applied means "show", not "hide again".
    public func toggle() {
        if wantsHidden {
            show(userInitiated: true)
        } else {
            hide()
        }
    }

    public func hide() {
        wantsHidden = true
        activate()
    }

    public func show(userInitiated: Bool = true) {
        wantsHidden = false
        generation += 1   // anything still in flight is now stale
        token?.invalidate()
        token = nil
        state = .shown
    }

    /// Quit (menu, Command-Q, logout, SIGTERM): release everything before the process exits.
    public func prepareForQuit() {
        wantsHidden = false
        generation += 1
        token?.invalidate()
        token = nil
    }

    // MARK: - Activation

    private func activate() {
        let hidden = preferences.hiddenBundleIDs
        guard !hidden.isEmpty else {
            // Never pay exam mode's side effects for nothing.
            wantsHidden = false
            state = .shown
            return
        }
        guard isInstalledCorrectly() else { return fail(.notInApplications) }
        guard restriction.isAvailable else { return fail(.frameworkMissing) }

        generation += 1
        let request = generation
        let allowed = AllowList.compute(running: runningBundleIDs(), hidden: hidden, own: ownBundleID)
        restriction.activate(allowing: allowed, systemItems: AllowList.systemItems) { [weak self] result in
            guard let self, request == self.generation, self.wantsHidden else {
                // Superseded by a later click, swap or quit: never let a late assertion stick.
                if case .success(let stale) = result { stale.invalidate() }
                return
            }
            switch result {
            case .success(let newToken):
                let previous = self.token
                self.token = newToken
                previous?.invalidate()   // the new list is live before the old one goes (spec 4.4)
                self.state = .hidden(count: hidden.count)
            case .failure(let error):
                // Already hiding with an older list: keep it rather than flash everything back (spec 4.4).
                if self.token != nil { return }
                self.fail(.activationFailed(error.localizedDescription))
            }
        }
    }

    private func fail(_ reason: UnavailableReason) {
        wantsHidden = false
        token?.invalidate()
        token = nil
        state = .unavailable(reason)
    }
}
```

```swift
import AppKit

/// A screen's geometry in global Cocoa coordinates (origin bottom-left).
public struct ScreenGeometry: Equatable, Sendable {
    public var frame: CGRect
    public var visibleFrame: CGRect

    public init(frame: CGRect, visibleFrame: CGRect) {
        self.frame = frame
        self.visibleFrame = visibleFrame
    }
}

/// "Busy" means: don't auto-hide right now (spec 4.5). It uses only the pointer position
/// and window layers, and neither needs Screen Recording permission.
public enum MenuBarBusyProbe {
    /// The menu bar strip at the top of a screen. Falls back to 24pt when the menu bar
    /// auto-hides and the screen has no top inset.
    public static func menuBarStrip(of screen: ScreenGeometry) -> CGRect {
        let inset = screen.frame.maxY - screen.visibleFrame.maxY
        let height = inset > 0 ? inset : 24
        return CGRect(x: screen.frame.minX, y: screen.frame.maxY - height, width: screen.frame.width, height: height)
    }

    /// Inclusive of the very top edge, where the pointer sits when pushed against it.
    public static func pointerInMenuBar(_ point: CGPoint, screens: [ScreenGeometry]) -> Bool {
        screens.contains { screen in
            let strip = menuBarStrip(of: screen)
            return point.x >= strip.minX && point.x < strip.maxX && point.y >= strip.minY && point.y <= strip.maxY
        }
    }

    /// True when any app has a pop-up menu on screen. Reads window layers only.
    public static func popUpMenuIsOpen() -> Bool {
        let level = Int(CGWindowLevelForKey(.popUpMenuWindow))
        let windows = CGWindowListCopyWindowInfo(.optionOnScreenOnly, kCGNullWindowID) as? [[String: Any]] ?? []
        return windows.contains { ($0[kCGWindowLayer as String] as? Int) == level }
    }

    @MainActor
    public static func isBusy() -> Bool {
        let screens = NSScreen.screens.map { ScreenGeometry(frame: $0.frame, visibleFrame: $0.visibleFrame) }
        return pointerInMenuBar(NSEvent.mouseLocation, screens: screens) || popUpMenuIsOpen()
    }
}
```

```swift
import AppKit

/// An sRGB color with WCAG relative luminance, so contrast can be checked in tests.
public struct RGB: Equatable, Sendable {
    public let red: UInt8
    public let green: UInt8
    public let blue: UInt8

    public init(hex: UInt32) {
        red = UInt8((hex >> 16) & 0xFF)
        green = UInt8((hex >> 8) & 0xFF)
        blue = UInt8(hex & 0xFF)
    }

    public var nsColor: NSColor {
        NSColor(srgbRed: CGFloat(red) / 255, green: CGFloat(green) / 255, blue: CGFloat(blue) / 255, alpha: 1)
    }

    /// WCAG 2.x relative luminance.
    public var relativeLuminance: Double {
        func channel(_ value: UInt8) -> Double {
            let c = Double(value) / 255
            return c <= 0.04045 ? c / 12.92 : pow((c + 0.055) / 1.055, 2.4)
        }
        return 0.2126 * channel(red) + 0.7152 * channel(green) + 0.0722 * channel(blue)
    }
}

public enum Contrast {
    /// WCAG contrast ratio: 1 means none, 21 is black on white.
    public static func ratio(_ a: RGB, _ b: RGB) -> Double {
        let high = max(a.relativeLuminance, b.relativeLuminance)
        let low = min(a.relativeLuminance, b.relativeLuminance)
        return (high + 0.05) / (low + 0.05)
    }
}

/// The drawer's amber, by menu bar appearance (spec 5.1). The bright amber measures only
/// 1.47:1 on a light menu bar, so light bars get a deeper shade (4.52:1).
public enum Palette {
    public static let amberOnDarkBar = RGB(hex: 0xFFB340)
    public static let amberOnLightBar = RGB(hex: 0xA35400)
    public static let handleOnDarkBar = RGB(hex: 0x17130E)
    public static let handleOnLightBar = RGB(hex: 0xFFFFFF)
    /// Reference menu bar backgrounds the contrast test measures against.
    public static let referenceDarkBar = RGB(hex: 0x1E1E1E)
    public static let referenceLightBar = RGB(hex: 0xE6E9F0)
}
```

```swift
import AppKit

/// The drawer icon (spec 5.1). Geometry comes from the approved mockup: a 16x14pt box,
/// y pointing down. `drawClosed(in:color:)` is shared with the app icon generator
/// (Sources/MakeIcon) so the geometry lives in one place.
public enum DrawerGlyph {
    public enum Variant: Equatable, Sendable {
        case closed
        case open(darkMenuBar: Bool)
        case unavailable
    }

    public static func image(_ variant: Variant) -> NSImage {
        switch variant {
        case .closed:
            return closedImage(alpha: 1)
        case .unavailable:
            return closedImage(alpha: 0.4)
        case .open(let dark):
            return openImage(body: dark ? Palette.amberOnDarkBar : Palette.amberOnLightBar,
                             handle: dark ? Palette.handleOnDarkBar : Palette.handleOnLightBar)
        }
    }

    /// Draws the closed drawer scaled into `rect`. The shape is vertically symmetric, so
    /// flipped and unflipped contexts draw it identically.
    public static func drawClosed(in rect: NSRect, color: NSColor) {
        NSGraphicsContext.saveGraphicsState()
        let transform = NSAffineTransform()
        transform.translateX(by: rect.minX, yBy: rect.minY)
        transform.scaleX(by: rect.width / 16, yBy: rect.height / 14)
        transform.concat()
        color.setStroke()
        let cabinet = NSBezierPath(roundedRect: NSRect(x: 1.5, y: 1.7, width: 13, height: 10.6), xRadius: 2.4, yRadius: 2.4)
        cabinet.lineWidth = 1.4
        cabinet.stroke()
        stroke(from: NSPoint(x: 1.5, y: 7), to: NSPoint(x: 14.5, y: 7), width: 1.4, round: false)
        stroke(from: NSPoint(x: 6.6, y: 4.4), to: NSPoint(x: 9.4, y: 4.4), width: 1.5, round: true)
        stroke(from: NSPoint(x: 6.6, y: 9.6), to: NSPoint(x: 9.4, y: 9.6), width: 1.5, round: true)
        NSGraphicsContext.restoreGraphicsState()
    }

    private static func closedImage(alpha: CGFloat) -> NSImage {
        let image = NSImage(size: NSSize(width: 16, height: 14), flipped: true) { rect in
            drawClosed(in: rect, color: NSColor.black.withAlphaComponent(alpha))
            return true
        }
        image.isTemplate = true   // the system tints it like every other menu bar icon
        return image
    }

    private static func openImage(body: RGB, handle: RGB) -> NSImage {
        let image = NSImage(size: NSSize(width: 18, height: 14), flipped: true) { _ in
            body.nsColor.setStroke()
            let cabinet = NSBezierPath(roundedRect: NSRect(x: 1.5, y: 1.7, width: 11, height: 10.6), xRadius: 2.4, yRadius: 2.4)
            cabinet.lineWidth = 1.4
            cabinet.stroke()
            body.nsColor.setFill()
            NSBezierPath(roundedRect: NSRect(x: 5.5, y: 6.3, width: 11, height: 6), xRadius: 1.6, yRadius: 1.6).fill()
            handle.nsColor.setStroke()
            stroke(from: NSPoint(x: 9.6, y: 9.3), to: NSPoint(x: 12.4, y: 9.3), width: 1.4, round: true)
            return true
        }
        image.isTemplate = false   // amber is the "icons are showing" signal
        return image
    }

    private static func stroke(from start: NSPoint, to end: NSPoint, width: CGFloat, round: Bool) {
        let path = NSBezierPath()
        path.move(to: start)
        path.line(to: end)
        path.lineWidth = width
        if round { path.lineCapStyle = .round }
        path.stroke()
    }
}
```

```swift
import AppKit
import Carbon.HIToolbox

/// What the right-click menu and the icon's accessibility label say, by state (spec 5.1, 5.2).
public struct MenuModel: Equatable, Sendable {
    public var toggleTitle: String
    public var toggleEnabled: Bool
    public var statusLine: String
    public var accessibilityLabel: String

    public static func make(state: HideState, hiddenCount: Int) -> MenuModel {
        switch state {
        case .hidden(let count):
            return MenuModel(toggleTitle: "Show Hidden Icons", toggleEnabled: true,
                             statusLine: "Hiding \(apps(count))",
                             accessibilityLabel: "Stow, \(apps(count)) hidden")
        case .shown:
            return MenuModel(toggleTitle: "Hide Icons", toggleEnabled: hiddenCount > 0,
                             statusLine: hiddenCount > 0 ? "All icons showing" : "Pick apps to hide in Settings",
                             accessibilityLabel: "Stow, icons showing")
        case .unavailable(let reason):
            let line = switch reason {
            case .notInApplications: "Move Stow to Applications to hide icons"
            case .frameworkMissing: "Hiding isn't available on this version of macOS"
            case .activationFailed(let message): "Hiding unavailable: \(message)"
            }
            return MenuModel(toggleTitle: "Show Hidden Icons", toggleEnabled: false,
                             statusLine: line, accessibilityLabel: "Stow, hiding unavailable")
        }
    }

    /// The global shortcut as a menu key equivalent, shown as a hint. Only letter and digit
    /// keys qualify; for other keys the menu shows no hint (the shortcut itself still works).
    @MainActor
    public static func keyEquivalent(for shortcut: Shortcut?,
                                     translate: @MainActor (UInt32) -> String? = KeyNames.layoutCharacter)
        -> (key: String, modifiers: NSEvent.ModifierFlags)? {
        guard let shortcut else { return nil }
        let name = KeyNames.name(for: shortcut.keyCode, translate: translate)
        guard name.count == 1, let scalar = name.unicodeScalars.first,
              CharacterSet.alphanumerics.contains(scalar) else { return nil }
        var flags: NSEvent.ModifierFlags = []
        if shortcut.modifiers & UInt32(controlKey) != 0 { flags.insert(.control) }
        if shortcut.modifiers & UInt32(optionKey) != 0 { flags.insert(.option) }
        if shortcut.modifiers & UInt32(shiftKey) != 0 { flags.insert(.shift) }
        if shortcut.modifiers & UInt32(cmdKey) != 0 { flags.insert(.command) }
        return (name.lowercased(), flags)
    }

    private static func apps(_ count: Int) -> String {
        count == 1 ? "1 app" : "\(count) apps"
    }
}
```

```swift
import AppKit

/// The drawer in the menu bar. Left-click toggles; right-click or Control-click opens the
/// menu (spec 5.1, 5.2).
@MainActor
public final class StatusItemController: NSObject, NSMenuDelegate {
    private let statusItem = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
    private let hideController: HideController
    private let preferences: Preferences
    private let openSettings: @MainActor () -> Void
    private var appearanceObservation: NSKeyValueObservation?

    public init(hideController: HideController, preferences: Preferences,
                openSettings: @escaping @MainActor () -> Void) {
        self.hideController = hideController
        self.preferences = preferences
        self.openSettings = openSettings
        super.init()
        statusItem.autosaveName = "stow_drawer"
        if let button = statusItem.button {
            button.target = self
            button.action = #selector(buttonClicked(_:))
            button.sendAction(on: [.leftMouseUp, .rightMouseUp])
            // Repaint the amber when the menu bar flips between light and dark.
            appearanceObservation = button.observe(\.effectiveAppearance) { [weak self] _, _ in
                MainActor.assumeIsolated { self?.refresh() }
            }
        }
        refresh()
    }

    /// Redraws the icon, tooltip and accessibility label from the current state.
    public func refresh() {
        guard let button = statusItem.button else { return }
        let model = MenuModel.make(state: hideController.state, hiddenCount: preferences.hiddenBundleIDs.count)
        button.image = DrawerGlyph.image(Self.variant(for: hideController.state, appearance: button.effectiveAppearance))
        button.toolTip = model.statusLine
        button.setAccessibilityLabel(model.accessibilityLabel)
    }

    static func variant(for state: HideState, appearance: NSAppearance) -> DrawerGlyph.Variant {
        switch state {
        case .hidden: .closed
        case .shown: .open(darkMenuBar: appearance.bestMatch(from: [.darkAqua, .aqua]) == .darkAqua)
        case .unavailable: .unavailable
        }
    }

    @objc private func buttonClicked(_ sender: NSStatusBarButton) {
        // On macOS 27, NSApp.currentEvent's modifier flags can be empty here (findings,
        // "Other traps"): decide by event type, and read Control from NSEvent.modifierFlags.
        let wantsMenu = NSApp.currentEvent?.type == .rightMouseUp || NSEvent.modifierFlags.contains(.control)
        if wantsMenu {
            showMenu()
        } else {
            hideController.toggle()
        }
    }

    private func showMenu() {
        let model = MenuModel.make(state: hideController.state, hiddenCount: preferences.hiddenBundleIDs.count)
        let menu = NSMenu()
        menu.delegate = self
        menu.autoenablesItems = false

        let toggle = NSMenuItem(title: model.toggleTitle, action: #selector(toggleFromMenu), keyEquivalent: "")
        toggle.target = self
        toggle.isEnabled = model.toggleEnabled
        if let hint = MenuModel.keyEquivalent(for: preferences.shortcut) {
            toggle.keyEquivalent = hint.key
            toggle.keyEquivalentModifierMask = hint.modifiers
        }
        menu.addItem(toggle)

        let status = NSMenuItem(title: model.statusLine, action: nil, keyEquivalent: "")
        status.isEnabled = false
        menu.addItem(status)
        menu.addItem(.separator())

        let settings = NSMenuItem(title: "Settings…", action: #selector(settingsFromMenu), keyEquivalent: ",")
        settings.target = self
        menu.addItem(settings)
        let quit = NSMenuItem(title: "Quit Stow", action: #selector(quitFromMenu), keyEquivalent: "q")
        quit.target = self
        menu.addItem(quit)

        statusItem.menu = menu
        statusItem.button?.performClick(nil)   // opens the menu under the drawer
    }

    public func menuDidClose(_ menu: NSMenu) {
        statusItem.menu = nil   // so the next left-click toggles again
    }

    @objc private func toggleFromMenu() { hideController.toggle() }
    @objc private func settingsFromMenu() { openSettings() }
    @objc private func quitFromMenu() { NSApp.terminate(nil) }
}
```

```swift
import Carbon.HIToolbox

public enum ShortcutError: Error, Equatable, LocalizedError {
    case inUse
    case failed(Int32)

    public var errorDescription: String? {
        switch self {
        case .inUse: "That shortcut is used by another app"
        case .failed(let status): "Couldn't register that shortcut (error \(status))"
        }
    }
}

/// Registers one system-wide hot key. Injected so tests never grab real key combinations.
@MainActor public protocol HotKeyRegistering: AnyObject {
    var onPress: (@MainActor () -> Void)? { get set }
    /// Replaces any current registration. Throws `ShortcutError.inUse` when another app owns it.
    func register(_ shortcut: Shortcut) throws
    func unregister()
}

/// Carbon's RegisterEventHotKey: global, and needs no Input Monitoring permission (spec 6.6).
@MainActor public final class CarbonHotKey: HotKeyRegistering {
    public var onPress: (@MainActor () -> Void)?
    private var hotKeyRef: EventHotKeyRef?
    private var handlerRef: EventHandlerRef?
    private static let signature: OSType = 0x53544F57   // 'STOW'

    public init() {}

    public func register(_ shortcut: Shortcut) throws {
        installHandlerIfNeeded()
        unregister()
        let id = EventHotKeyID(signature: Self.signature, id: 1)
        let status = RegisterEventHotKey(shortcut.keyCode, shortcut.modifiers, id,
                                         GetApplicationEventTarget(), 0, &hotKeyRef)
        guard status == noErr else {
            hotKeyRef = nil
            throw status == OSStatus(eventHotKeyExistsErr) ? ShortcutError.inUse : ShortcutError.failed(status)
        }
    }

    public func unregister() {
        if let hotKeyRef { UnregisterEventHotKey(hotKeyRef) }
        hotKeyRef = nil
    }

    private func installHandlerIfNeeded() {
        guard handlerRef == nil else { return }
        var spec = EventTypeSpec(eventClass: OSType(kEventClassKeyboard), eventKind: UInt32(kEventHotKeyPressed))
        let context = Unmanaged.passUnretained(self).toOpaque()
        InstallEventHandler(GetApplicationEventTarget(), { _, _, userData in
            guard let userData else { return noErr }
            let hotKey = Unmanaged<CarbonHotKey>.fromOpaque(userData).takeUnretainedValue()
            // Carbon delivers hot key events on the main thread.
            MainActor.assumeIsolated { hotKey.onPress?() }
            return noErr
        }, 1, &spec, context, &handlerRef)
    }
}

/// Keeps the saved shortcut registered, and swaps it safely (spec 6.6).
@MainActor public final class ShortcutController {
    public private(set) var lastError: String?
    private let registrar: any HotKeyRegistering
    private let preferences: Preferences

    public init(registrar: any HotKeyRegistering, preferences: Preferences,
                onPress: @escaping @MainActor () -> Void) {
        self.registrar = registrar
        self.preferences = preferences
        registrar.onPress = onPress
    }

    /// Registers the saved shortcut at launch.
    public func start() {
        guard let shortcut = preferences.shortcut else { return }
        do {
            try registrar.register(shortcut)
            lastError = nil
        } catch {
            lastError = error.localizedDescription
        }
    }

    /// Tries a new shortcut; nil clears it. On failure the previous shortcut stays
    /// registered and saved, and `lastError` says why.
    @discardableResult
    public func apply(_ shortcut: Shortcut?) -> Bool {
        guard let shortcut else {
            registrar.unregister()
            preferences.shortcut = nil
            lastError = nil
            return true
        }
        let previous = preferences.shortcut
        do {
            try registrar.register(shortcut)
            preferences.shortcut = shortcut
            lastError = nil
            return true
        } catch {
            lastError = error.localizedDescription
            if let previous { try? registrar.register(previous) }
            return false
        }
    }
}
```

```swift
import ApplicationServices

/// An app that currently shows at least one menu bar icon.
public struct MenuBarApp: Equatable, Sendable {

    public var name: String

        self.bundleID = bundleID
        self.name = name

/// One row of the Settings list (spec 5.3).
public struct ListedApp: Equatable, Identifiable, Sendable {
    public var id: String { bundleID }
    public var bundleID: String
    public var name: String
    public var isRunning: Bool
    public var isHidden: Bool

    public init(bundleID: String, name: String, isRunning: Bool, isHidden: Bool) {
        self.bundleID = bundleID
        self.name = name
        self.isRunning = isRunning
        self.isHidden = isHidden
    }
}

public enum InventoryMerge {
    /// Apps with menu bar icons, plus every hidden app (so it can be un-hidden), minus Stow.
    /// `running` decides "Not running", because apps Stow is hiding may be missing from `found`.
    public static func merge(found: [MenuBarApp], hidden: [String], running: Set<String>,
                             ownBundleID: String, nameFor: (String) -> String?) -> [ListedApp] {
        let hiddenSet = Set(hidden)
        var rows: [String: ListedApp] = [:]
        for app in found where app.bundleID != ownBundleID {
            rows[app.bundleID] = ListedApp(bundleID: app.bundleID, name: app.name, isRunning: true,
                                           isHidden: hiddenSet.contains(app.bundleID))
        }
        for id in hiddenSet where id != ownBundleID && rows[id] == nil {
            rows[id] = ListedApp(bundleID: id, name: nameFor(id) ?? id, isRunning: running.contains(id), isHidden: true)
        }
        return rows.values.sorted { a, b in
            let order = a.name.localizedCaseInsensitiveCompare(b.name)
            return order == .orderedSame ? a.bundleID < b.bundleID : order == .orderedAscending
        }
    }
}

/// What Settings needs from the Accessibility scan. Injected so tests don't need permissions.
@MainActor public protocol InventoryScanning: AnyObject {
    var isTrusted: Bool { get }
    func requestTrust()
    func scan() async -> [MenuBarApp]
    func displayName(for bundleID: String) -> String?
}

/// Finds which running apps have menu bar icons, through Accessibility (spec 6.5).
/// Accessibility is the only permission Stow ever asks for.
@MainActor public final class MenuBarAppInventory: InventoryScanning {
    public init() {}

    public var isTrusted: Bool {
        // The kAXTrustedCheckOptionPrompt global isn't concurrency-safe in Swift 6; use its value.
        AXIsProcessTrustedWithOptions(["AXTrustedCheckOptionPrompt": false] as CFDictionary)
    }

    /// Adds Stow to the Accessibility list and opens that privacy pane.
    public func requestTrust() {
        _ = AXIsProcessTrustedWithOptions(["AXTrustedCheckOptionPrompt": true] as CFDictionary)
        if let url = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility") {
            NSWorkspace.shared.open(url)
        }
    }

    public func scan() async -> [MenuBarApp] {
        guard isTrusted else { return [] }
        let candidates = NSWorkspace.shared.runningApplications
            .filter { $0.activationPolicy == .regular || $0.activationPolicy == .accessory }
            .compactMap { app -> Candidate? in
                guard let id = app.bundleIdentifier else { return nil }
                return Candidate(pid: app.processIdentifier, bundleID: id, name: app.localizedName ?? id)
            }
        // Off the main thread: an unresponsive app can make each Accessibility call wait 0.25s.
        return await Task.detached(priority: .userInitiated) {
            MenuBarAppInventory.appsWithMenuBarItems(candidates)
        }.value
    }

    public func displayName(for bundleID: String) -> String? {
        NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID)?
            .deletingPathExtension().lastPathComponent
    }

    struct Candidate: Sendable {
        let pid: pid_t
        let bundleID: String
        let name: String
    }

    nonisolated static func appsWithMenuBarItems(_ candidates: [Candidate]) -> [MenuBarApp] {
        candidates.compactMap { candidate in
            let element = AXUIElementCreateApplication(candidate.pid)
            AXUIElementSetMessagingTimeout(element, 0.25)
            var value: CFTypeRef?
            guard AXUIElementCopyAttributeValue(element, "AXExtrasMenuBar" as CFString, &value) == .success,
                  let bar = value, CFGetTypeID(bar) == AXUIElementGetTypeID() else { return nil }
            var children: CFTypeRef?
            guard AXUIElementCopyAttributeValue(unsafeDowncast(bar, to: AXUIElement.self),
                                                "AXChildren" as CFString, &children) == .success,
                  let items = children as? [AnyObject], !items.isEmpty else { return nil }
            return MenuBarApp(bundleID: candidate.bundleID, name: candidate.name)
        }
    }
}
```

```swift
/// A field that records the next key combination (spec 6.6). Click it, then press keys.
/// Esc cancels; Delete clears it (no shortcut). Needs at least one of Control, Option or Command.
struct ShortcutRecorder: NSViewRepresentable {
    var shortcut: Shortcut?
    var onChange: @MainActor (Shortcut?) -> Void

    func makeNSView(context: Context) -> RecorderField {
        let field = RecorderField()
        field.shortcut = shortcut
        field.onChange = onChange
        return field
    }

    func updateNSView(_ field: RecorderField, context: Context) {
        field.onChange = onChange
        if !field.isRecording { field.shortcut = shortcut }
    }
}

final class RecorderField: NSView {
    var shortcut: Shortcut? { didSet { needsDisplay = true } }
    var onChange: (@MainActor (Shortcut?) -> Void)?
    /// Played when a combination has no Control, Option or Command. Tests replace it.
    var beep: @MainActor () -> Void = { NSSound.beep() }
    private(set) var isRecording = false { didSet { needsDisplay = true } }

    override var acceptsFirstResponder: Bool { true }
    override var intrinsicContentSize: NSSize { NSSize(width: 140, height: 22) }

    func beginRecording() { isRecording = true }

    override func mouseDown(with event: NSEvent) {
        beginRecording()
        window?.makeFirstResponder(self)
    }

    override func resignFirstResponder() -> Bool {
        isRecording = false
        return super.resignFirstResponder()
    }

    override func performKeyEquivalent(with event: NSEvent) -> Bool {
        guard isRecording else { return super.performKeyEquivalent(with: event) }
        keyDown(with: event)
        return true
    }

    override func keyDown(with event: NSEvent) {
        guard isRecording else { return super.keyDown(with: event) }
        switch Int(event.keyCode) {
        case kVK_Escape:
            isRecording = false
        case kVK_Delete, kVK_ForwardDelete:
            isRecording = false
            shortcut = nil
            onChange?(nil)
        default:
            guard let recorded = Shortcut.from(keyCode: event.keyCode, flags: event.modifierFlags) else {
                beep()
                return
            }
            isRecording = false
            shortcut = recorded
            onChange?(recorded)
        }
    }

    override func draw(_ dirtyRect: NSRect) {
        let path = NSBezierPath(roundedRect: bounds.insetBy(dx: 0.5, dy: 0.5), xRadius: 6, yRadius: 6)
        (isRecording ? NSColor.controlAccentColor.withAlphaComponent(0.15) : NSColor.quaternaryLabelColor).setFill()
        path.fill()
        (isRecording ? NSColor.controlAccentColor : NSColor.separatorColor).setStroke()
        path.lineWidth = 1
        path.stroke()
        let text = isRecording ? "Type shortcut…" : (shortcut?.displayString() ?? "None")
        let attributes: [NSAttributedString.Key: Any] = [
            .font: NSFont.systemFont(ofSize: 12),
            .foregroundColor: (isRecording || shortcut == nil) ? NSColor.secondaryLabelColor : NSColor.labelColor,
        ]
        let size = text.size(withAttributes: attributes)
        text.draw(at: NSPoint(x: bounds.midX - size.width / 2, y: bounds.midY - size.height / 2),
                  withAttributes: attributes)
    }

    // VoiceOver: a button that starts recording.
    override func isAccessibilityElement() -> Bool { true }
    override func accessibilityRole() -> NSAccessibility.Role? { .button }
    override func accessibilityLabel() -> String? {
        "Keyboard shortcut: " + (shortcut?.displayString() ?? "None")
    }
    override func accessibilityPerformPress() -> Bool {
        beginRecording()
        window?.makeFirstResponder(self)
        return true
    }
}
```

```swift
public final class AppController {
    private let preferences: Preferences

    private let shortcutController: ShortcutController
    private let loginItem = LoginItem()
    private let inventory = MenuBarAppInventory()

    public init() {
        let preferences = Preferences()
        let ownBundleID = Bundle.main.bundleIdentifier ?? StowKit.bundleIdentifier
        let hideController = HideController(
            restriction: ExamModeRestriction(),
            preferences: preferences,
            scheduler: TaskScheduler(),

            isBusy: { MenuBarBusyProbe.isBusy() },
            ownBundleID: ownBundleID)
        self.preferences = preferences
        self.ownBundleID = ownBundleID
        self.hideController = hideController
        self.shortcutController = ShortcutController(registrar: CarbonHotKey(), preferences: preferences,
                                                     onPress: { hideController.toggle() })

    public func launch() {

            preferences: preferences,
            hideController: hideController,
            inventory: inventory,
            loginItem: loginItem,
            shortcuts: shortcutController,
            ownBundleID: ownBundleID,
            runningBundleIDs: { RunningApps.bundleIDs() },
            isInstalled: { InstallLocation.isExpected(Bundle.main.bundleURL) },
            openURL: { url in
                // Fallback for open question 5: if the pane link fails, open System Settings itself.
                if !NSWorkspace.shared.open(url) {
                    NSWorkspace.shared.open(URL(fileURLWithPath: "/System/Applications/System Settings.app"))
                }
            })
        let settingsWindow = SettingsWindowController(model: model)
        self.settingsWindow = settingsWindow
        let statusItem = StatusItemController(hideController: hideController, preferences: preferences,
                                              openSettings: { settingsWindow.show() })
        self.statusItem = statusItem
        hideController.onStateChange = { _ in statusItem.refresh() }
        model.onChange = { statusItem.refresh() }

        shortcutController.start()
        observeAppLaunches()
        routeTerminationSignal()

        if FirstRun.isNeeded(preferences) {
            try? loginItem.setEnabled(true)   // Open at login defaults to on (spec 5.5)
            preferences.hasCompletedFirstRun = true
            settingsWindow.show()
        }
        hideController.start()
        statusItem.refresh()
    }

    /// Called from applicationWillTerminate: release the assertion before the process exits.
    public func terminate() {
        hideController.prepareForQuit()
    }

    private func observeAppLaunches() {
        let hideController = hideController
        launchObserver = NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didLaunchApplicationNotification, object: nil, queue: .main) { _ in
            MainActor.assumeIsolated { hideController.appLaunched() }
        }

    /// without applicationWillTerminate. Route it through NSApp.terminate so the assertion is released.

        let source = DispatchSource.makeSignalSource(signal: SIGTERM, queue: .main)
        source.setEventHandler {
            MainActor.assumeIsolated { NSApp.terminate(nil) }
        }
        source.resume()
        terminationSignal = source
    }
```

```swift
        let name = scale == 1 ? "icon_\(points)x\(points).png" : "icon_\(points)x\(points)@2x.png"
        try renderIcon(pixels: points * scale).write(to: iconset.appendingPathComponent(name))
    }
}

iconutil.executableURL = URL(fileURLWithPath: "/usr/bin/iconutil")
iconutil.arguments = ["-c", "icns", iconset.path, "-o", output]
try iconutil.run()
iconutil.waitUntilExit()
try? FileManager.default.removeItem(at: iconset)
guard iconutil.terminationStatus == 0 else {
    FileHandle.standardError.write(Data("iconutil failed with status \(iconutil.terminationStatus)\n".utf8))
    exit(1)
}
```

`scripts/install.sh`:

```zsh
#!/bin/zsh
# Builds Stow, signs it with your Apple Development identity, installs it to
# /Applications and relaunches it. Exam mode only recognizes the installed copy,
# so this is the dev loop (spec 6.7). Usage: scripts/install.sh
set -euo pipefail
cd "${0:A:h}/.."

APP="build/Stow.app"
INSTALLED="/Applications/Stow.app"

echo "Building release..."
swift build -c release --product Stow
BIN_DIR="$(swift build -c release --product Stow --show-bin-path)"

echo "Assembling $APP..."
rm -rf "$APP"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
cp "$BIN_DIR/Stow" "$APP/Contents/MacOS/Stow"
BUILD_NUMBER="$(git rev-list --count HEAD 2>/dev/null || echo 1)"
sed "s/__BUILD_NUMBER__/$BUILD_NUMBER/" Resources/Info.plist > "$APP/Contents/Info.plist"
plutil -lint -s "$APP/Contents/Info.plist"
cp Resources/AppIcon.icns "$APP/Contents/Resources/AppIcon.icns"

# A stable identity keeps the Accessibility grant across rebuilds; ad-hoc signing resets it every time.
IDENTITY="$(security find-identity -v -p codesigning | awk -F'"' '/Apple Development:/ { print $2; exit }')"
if [[ -z "$IDENTITY" ]]; then
  echo "No 'Apple Development' signing identity in your keychain. Add one in Xcode > Settings > Accounts." >&2
  exit 1
fi
echo "Signing with: $IDENTITY"
codesign --force --sign "$IDENTITY" --timestamp=none "$APP"

# Quit the running copy first so it releases its exam-mode assertion (SIGTERM is routed to a clean quit).
if pgrep -x Stow >/dev/null; then
  echo "Quitting the running Stow..."
  pkill -TERM -x Stow || true
  for _ in {1..50}; do pgrep -x Stow >/dev/null || break; sleep 0.1; done
  if pgrep -x Stow >/dev/null; then
    echo "Stow didn't quit within 5 seconds; stopping here." >&2
    exit 1
  fi
fi

echo "Installing to $INSTALLED..."
rm -rf "$INSTALLED"
ditto "$APP" "$INSTALLED"
open "$INSTALLED"

# A build isn't an install: verify what's installed and what's actually running.
codesign --verify --strict "$INSTALLED"
AUTHORITY="$(codesign -dvv "$INSTALLED" 2>&1 | awk -F= '/^Authority=/ { print $2; exit }')"
if [[ "$AUTHORITY" != Apple\ Development:* ]]; then
  echo "Unexpected signing authority: '$AUTHORITY'" >&2
  exit 1
fi
for _ in {1..50}; do pgrep -f "^$INSTALLED/Contents/MacOS/Stow" >/dev/null && break; sleep 0.1; done
if ! pgrep -f "^$INSTALLED/Contents/MacOS/Stow" >/dev/null; then
  echo "Stow isn't running from $INSTALLED." >&2
  exit 1
fi
VERSION="$(defaults read "$INSTALLED/Contents/Info" CFBundleShortVersionString)"
echo "Installed Stow $VERSION (build $BUILD_NUMBER), signed by $AUTHORITY, running from $INSTALLED."
```

Run: `chmod +x scripts/install.sh`

````markdown
# Stow

A personal macOS 27 menu bar utility that hides the menu bar icons of apps you choose behind one drawer icon. It replaces Hidden Bar, whose App Store build stopped hiding anything on macOS 27.

- Design: `docs/superpowers/specs/2026-10-12-stow-design.md`
- Why it works this way: `docs/macos-27-menu-bar-findings.md`
- On-device results: `docs/verification.md`

## Install or update

```bash
scripts/install.sh
```

This builds Stow, signs it with your Apple Development identity, installs it to `/Applications/Stow.app` and relaunches it. Stow must run from `/Applications`, because exam mode doesn't recognize any other copy.

## Test

```bash
swift test
```

## Use

- Click the drawer to hide or show the apps you chose. Right-click or Control-click it for the menu.
- In Settings you can pick the apps to hide, the re-hide delay, the keyboard shortcut (Control-Option-H by default) and open at login.
- Grant Accessibility when asked. Stow only uses it to list which apps have menu bar icons, and never needs Screen Recording.

## Known limits

- Hiding is per app, so all of an app's icons hide together.
- While icons are hidden, macOS's exam mode is on. Clicking the clock won't open Notification Center, and Focus and Now Playing may be hidden too.
- Icons from tools without a bundle ID hide whenever Stow hides.
- Stow relies on a private macOS framework (MenuBarClientCore). If a macOS update breaks it, Stow shows "unavailable" and leaves every icon visible.

```
````
